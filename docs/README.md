# OnyX · документация

OnyX — AI-ассистент с нейросетью, работающей **прямо в браузере**.

## Как это работает

- Встроенный самообучаемый трансформер (BPE-токенизатор, multi-head attention,
  AdamW, обучение в фоне) исполняется в Web Worker браузера.
- Никакого Python-сервера, больших моделей и облачных ключей не нужно.
- Работает на GitHub Pages, локально из файла, офлайн.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Весь сайт: интерфейс + нейросеть + обучение |
| `core/` | JS-модули движка (корпус, engine) |
| `web/` | Поиск, изображения, видео |
| `tests/` | JS-тесты движка |

## Быстрый старт

Открой `index.html` — нейросеть уже готова отвечать. Или разверни на
GitHub Pages: Settings → Pages → ветка main → root.

## Ограничения

- Трансформер небольшой (посимвольная/BPE токенизация) — ответы короче
  и проще, чем у больших LLM, но полностью автономны.
- Обучение идёт локально в браузере, прогресс сохраняется в IndexedDB.
