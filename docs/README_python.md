# OnyX AI v0.5 — самообучаемая нейросеть

Полноценная языковая модель с двумя ядрами:

1. **Python-ядро (новое)** — `python_core/`: настоящий трансформер на Python + numpy
   (BPE-токенизатор, multi-head self-attention, backprop, Adam), богатая база знаний,
   локальный HTTP-сервер для ответов, генерации изображений и видео.
2. **JS-ядро** — встроенный в `index.html` трансформер на JavaScript с Web Worker.
   Работает в любом браузере как fallback, даже без Python.

## Как запустить

### Вариант 1. Полный (рекомендуется) — с Python-сервером

1. Двойной клик по **`start_server.bat`** — запустится Python-сервер
   на `http://127.0.0.1:8787`.
2. Открой **`index.html`** в браузере (двойной клик или перетащи в окно браузера).
3. В левом верхнем углу появится индикатор «Python-ядро» — если сервер запущен,
   отвечать будет умное Python-ядро; иначе интерфейс использует JS-движок.

### Вариант 2. Только браузер (без Python)

Просто открой `index.html`. Всё работает автономно на JS-движке
(изображения и видео генерируются в браузере, поиск — через открытые API).

## Возможности

- **Программирование**: отдельная база знаний на 68 статей по 20 темам — Python,
  JavaScript/TypeScript, C++, C#, Java, Go, Rust, SQL (JOIN, индексы, оконные
  функции), HTML/CSS, HTTP/REST/CORS, безопасность (SQL-инъекции, XSS, JWT),
  алгоритмы и структуры данных, Git, Docker, Linux, паттерны и чистый код.
  Ответ идёт из статьи с рабочим примером кода, а не «сочиняется» моделью.
- **Решение сложных задач**: точный решатель — арифметика с приоритетом операций
  и функциями (sqrt, log, sin…), линейные и квадратные уравнения, системы 2×2
  по Крамеру, проценты и скидки, арифметическая и геометрическая прогрессии,
  факториал/сочетания/перестановки/размещения, НОД/НОК, проверка на простоту,
  разложение на множители, перевод единиц и температуры, задачи на движение.
  Каждый ответ сопровождается пошаговым решением, шаги видны в «рассуждении».
- **Текстовые ответы**: трансформер на Python (а также JS) + база знаний из сотен
  фактов + тихий веб-поиск, который плавно вплетается в ответ без списка ссылок.
- **Режим мышления**: перед ответом модель строит понятную цепочку рассуждений —
  какое намерение распознано, какие ключевые понятия, сколько фактов найдено,
  степень уверенности. Шаги видны в панели «Показать рассуждение».
- **Поиск в интернете (бесплатные API)**: Wikipedia (RU/EN), DuckDuckGo, Bing,
  Openverse — несколько источников объединяются, нежелательный контент
  фильтруется, результаты вплетаются в ответ.
- **Генерация изображений**: несколько уровней — Pollinations AI (бесплатная
  генерация по промпту) → Openverse (реальные фото/арт) → объектный движок
  (процедурная отрисовка объектов) → абстракция. Водяной знак OnyX всегда в углу.
- **Генерация видео**: объектный движок анимирует сцену (птицы, бабочки, волны,
  солнце), при доступности Pollinations добавляются сгенерированные кадры с
  панорамой/зумом. MP4 с движущимся по углам водяным знаком.
- **Заставка при запуске**: видео из `assets/splash/onyx_intro.mp4`, без кнопок,
  плавно исчезает.
- **Самообучение (в реальном времени)**: модель дообучается на каждом диалоге
  (вопрос→ответ), на найденных в интернете текстах и на промптах генерации
  изображений/видео — один быстрый шаг обучения за каждый обмен, прогресс
  сохраняется в чекпоинт.

## Модель и параметры

Трансформер конфигурируется пресетами из `engine/transformer.py`. Реальные
значения проверены через `model.num_params()` при словаре 1578 токенов:

| Пресет | Параметры | Шаг обучения (CPU, батч 4×64) |
|---|---|---|
| `nano` (рабочий) | 449 280 | ~64 мс |
| `nano2` | 166 800 | ~30 мс |
| `micro` | 1 416 448 | ~120 мс |
| `small` | 3 021 696 | ~250 мс |
| `medium` | 6 804 480 | ~0.55 с |
| `large` | 18 498 816 | ~1.4 с |
| `xl` | 38 899 712 | ~3.4 с |
| `xxl` | 86 661 120 | ~7.7 с |

Рабочий сервер использует `nano` — он даёт мгновенный ответ. Большие пресеты
можно создать и обучать (`python_core/train_max.py <минуты> <пресет> [lr]`),
но на CPU они учатся медленно: `xxl` — около 7.7 с на шаг, то есть за час лишь
~470 шагов.

### Почему не 2 млрд параметров

2 млрд параметров в float32 — это ~8 ГБ только на веса. Для обучения нужны ещё
градиенты и два состояния Adam: суммарно ~32 ГБ памяти при 16 ГБ на машине, плюс
терафлопсы вычислений. Поэтому модель такого размера физически не запускается на
этом компьютере — ни обучить, ни даже загрузить. Вместо имитации «миллиарда»
OnyX берёт другим: точной базой знаний, решателем задач, поиском и обучением на
диалогах. По реальной пользе на бытовых вопросах и задачах это сильнее, чем
нетренированный трансформер на 100 млн параметров.

## Примечание о «ChatGPT 6» и больших моделях

ChatGPT 6 не существует. Обучение локальной модели до уровня современных
серверных LLM невозможно на персональном компьютере (нужны тысячи GPU-часов).
Модель на 2 млрд параметров тоже не помещается в 16 ГБ памяти вместе с
градиентами и оптимизатором. Поэтому OnyX v0.5 — честная гибридная система:
обучаемый трансформер + база знаний + точный решатель + тихий поиск, что даёт
полезные, связные и проверяемые ответы на многих реальных вопросах.
