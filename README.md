# OnyX Ai

<div align="center">

**OnyX** — интеллектуальный AI-ассистент с минималистичным дизайном, плавными анимациями и поддержкой нескольких провайдеров ИИ.

![Лицензия](https://img.shields.io/badge/лицензия-Proprietary-lightgrey)

</div>

---

## 🌟 Особенности

- **Адаптивный дизайн**: Оптимизирован для мобильных устройств и PWA
- **Анимации**: Плавные эффекты в стиле Nothing OS с красными акцентами
- **Темы оформления**: Чёрная (Nothing), светлая и тёмная темы
- **Поиск информации**: Интеграция с Википедией и DuckDuckGo
- **Генерация изображений**: Создание картинок через внешние API
