# OnyX 4.1 ULTIMATE · Nothing style

Проект от **CodeXY Labs ™** | Разработчик: **LumiXeN** | 2026

## Описание

OnyX 4.1 ULTIMATE — это стильная веб-страница в эстетике бренда **Nothing**, выполненная в минималистичном дизайне с характерными красными акцентами и эффектом жидкого стекла (Liquid Glass).

## Особенности

- 🎨 **Дизайн в стиле Nothing** — минимализм с красно-чёрной цветовой схемой
- 💎 **Liquid Glass эффект** — современное стекло с размытием и глубиной
- 📱 **Адаптивность** — поддержка мобильных устройств и safe-area insets
- ⚡ **Плавные анимации** — кастомные bezier-кривые для естественных переходов
- 🔤 **Типографика** — комбинация шрифтов Doto, Space Grotesk и JetBrains Mono

## Технологии

- HTML5
- CSS3 (Custom Properties, Glassmorphism)
- Google Fonts (Doto, Space Grotesk, JetBrains Mono)

## Запуск

Просто откройте файл `index.html` в любом современном браузере:

```bash
# Локально
open index.html

# Или через Python HTTP сервер
python3 -m http.server 8000
```
