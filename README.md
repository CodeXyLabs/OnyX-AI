- **Несколько провайдеров ИИ**: Поддержка Ollama (локально), Hugging Face (облако) и офлайн-режима

- **Генерация изображений**: Создание картинок через внешние API

## 🚀 Быстрый старт

### Вариант 1: Использование без нейросетей (офлайн)
Просто откройте `index.html` в браузере. Поиск и база знаний будут работать.

### Вариант 2: Подключение Ollama (рекомендуется)

1. **Установите Ollama**:
   ```bash
   # macOS / Linux
   curl -fsSL https://ollama.com/install.sh | sh
   
   # Windows — скачайте с https://ollama.com
   ```

2. **Загрузите модель**:
   ```bash
   ollama pull llama3
   # или другую: mistral, gemma, qwen2.5 и т.д.
   ```

3. **Запустите сервер с CORS** (важно для работы из браузера):
   ```bash
   OLLAMA_ORIGINS="*" ollama serve
   ```

4. **Настройте OnyX**:
   - Откройте `index.html`
   - Нажмите ⚙️ Настройки
   - Выберите провайдер **Ollama (Local)**
   - Укажите URL (обычно `http://localhost:11434`)
   - Введите имя модели (например, `llama3`)
   - Нажмите **🔍 Проверить соединение**
   - Сохраните настройки

### Вариант 3: Подключение Hugging Face

1. Получите бесплатный токен на [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
2. В настройках OnyX выберите **Hugging Face (Cloud)**
3. Вставьте токен и выберите модель

## 🔧 API для внешних нейросетей

### Ollama (локальный)
- **URL**: `http://localhost:11434/api/chat`
- **Модели**: Любые, установленные через `ollama pull`
- **Плюсы**: Бесплатно, приватно, быстро
- **Минусы**: Требует установки, нужен CORS

### Hugging Face (облачный)
- **URL**: `https://api-inference.huggingface.co/models/{model}`
- **Модели**: Mistral 7B, Llama 3, Gemma, Qwen и др.
- **Плюсы**: Не требует установки, много моделей
- **Минусы**: Нужен токен, есть лимиты

## 🆘 Troubleshooting

### «Ошибка подключения к Ollama»
- Убедитесь, что сервер запущен: `ollama serve`
- Проверьте CORS: `OLLAMA_ORIGINS="*"` перед запуском
- Попробуйте `http://127.0.0.1:11434` вместо `localhost`

### «Требуется токен Hugging Face»
- Зарегистрируйтесь на huggingface.co
- Создайте токен в Settings → Tokens
- Вставьте в настройках OnyX

### Анимации тормозят
- Отключите тяжёлые эффекты в CSS
- Используйте `will-change` осторожно
- Уменьшите количество частиц на фоне
