# OnyX Ai

<div align="center">

**OnyX** — интеллектуальный AI-ассистент с минималистичным красно-чёрным дизайном. Нейросеть работает **прямо в браузере** — без сервера, без облака, без ключей.

## 🌟 Возможности

- **Нейросеть в браузере**: самообучаемый трансформер (BPE + multi-head attention + AdamW) работает в Web Worker — на GitHub Pages, офлайн, с file://, на любом хостинге
- **Режим мышления**: пошаговое рассуждение перед ответом
- **Поиск по сети**: Wikipedia, DuckDuckGo — незаметно вплетается в ответ
- **Блоки-цитаты и код**: ответы и код в кавычках — в закруглённых прямоугольниках с кнопкой **КОПИРОВАТЬ**
- **Генерация изображений** с водяным знаком OnyX (через открытые API)
- Никакого Python, никакой большой модели ~3 ГБ — всё в одном `index.html`

## 🚀 Демо

Живой сайт: **https://codexylabs.github.io/OnyX-AI/**

Просто открой — нейросеть уже работает в браузере. Сервер не нужен.

## 📁 Структура

```
index.html    — весь сайт (интерфейс + нейросеть + обучение)
core/         — JS-модули движка
web/          — поиск, изображения, видео
docs/         — документация
```

## 🛠 Запуск локально

Открой `index.html` двойным кликом или:

```bash
npx serve .
```

## ⚠️ Безопасность

- Коды активации (`onyx_activation_codes_*.txt`) в репозиторий не загружаются.
- Модель не покидает браузер: веса в IndexedDB, данные не отправляются на серверы (кроме тихого поиска по сети).
