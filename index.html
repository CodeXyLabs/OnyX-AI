⚙ Настройки
Qwen · облачный ключ (OpenRouter или HuggingFace)
Облачная Qwen нужна, когда нет запущенного локального сервера (например на GitHub Pages). Ключ: OpenRouter (openrouter.ai/settings/keys → Create Key, формат sk-or-v1-...) или HuggingFace (huggingface.co/settings/tokens, формат hf_..., у Qwen есть бесплатный тариф). Без ключа и без локального сервера Qwen ответить не сможет.

Локальный сервер python_core/server.py даёт ответы трансформера на Python, генерацию изображений и видео с водяным знаком. Для запуска: start_server.bat в папке проекта.
Обучение
Модель обучается сама: она читает диалоги, ответы движка и найденные источники, считает градиенты и обновляет веса прямо в браузере. Прогресс сохраняется, поэтому обучение продолжается с того места, где остановилось.
Проверить модель из консоли браузера: OnyXLLM.ask('вопрос') · OnyXLLM.train(60) · OnyXLLM.status()
